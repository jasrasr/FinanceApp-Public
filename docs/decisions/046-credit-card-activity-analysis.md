# ADR 046: Credit Card Activity Analysis

## Status

Accepted

## Decision

Add a read-only credit-card activity analysis backed by the existing report
rollforward. The report filters the existing debt activity records to
credit-card debts and exposes monthly portfolio rows plus per-card summaries
for the selected period. No ledger, balance, transaction, or schema mutation
is performed.

## Rationale

Using the established rollforward preserves the existing treatment of
Purchase/Charge, payment principal, borrowing/draw, transfer, interest, fee,
and adjustment activity. Per-card views are generated by running that same
function for each selected credit-card record, so portfolio and individual-card
reconciliations use identical accounting rules.

Usage descriptions are deliberately conservative heuristics. The UI may show a
card as transactional/pay-in-full only when the period has purchases, no
ending balance, and no interest; it may show carried-balance debt only when an
ending balance and interest are both present. Otherwise it reports insufficient
data and never changes the debt record.
